2026-09-26。俯视 2D 浏览器游戏，第一到第十天已可连续游玩。

## 启动与操作

在本目录运行 `node server.cjs`，打开 http://127.0.0.1:4390/ 。无需 npm 安装。手机在同一网络时可使用电脑局域网 IP 加 4390 端口，需防火墙允许；手机实体测试尚未进行。

WASD / 方向键移动；点击地面自动寻路；靠近人或物件按 E / 空格互动，也可直接点击目标。手机横屏使用摇杆和互动按钮。对话点击画面先补全、再推进；选择放在对话下面，可用 1/2/3。

每一天：自由走动 → 突发事件 → 找人聊聊 → 选择与处理 → 关灯晚安 → 自己回床 → 日终页。点击「睡醒，继续明天」进入下一天；也可以保存后以后再来。第十天回床后出现最终后日谈，不生成第十一天。

## 十天内容

1. 沙发客上门：共同商量许川暂住、收箱子、铺毯子。
2. 冰箱里那盒布丁：误拿食物，决定共用与私人物品怎么放。
3. 镜头扫过的五秒：未经同意入镜，处理视频与拍摄边界。
4. 第三晚到了：兑现讨论日期，重新商量暂住期限。
5. 洗衣机没停过：晾衣和画纸挤在一起，调整空间。
6. 一锅饭，四个时间：一起吃饭还是各自留饭。
7. 投错地方的简历：许川求职受挫，决定怎么帮忙。
8. 跳闸那一下：停用故障设备、安排检修和晚餐。
9. 这十天谁在收拾：讨论家务分配，不能默认借住者包揽。
10. 便签还贴着：回看共同生活，决定以后如何沟通。

四间卧室分别属于玩家、林砚、苏白、陈灿。玩家是同住的房东，不以产权替大家决定公共空间；许川暂住客厅。第一天只住一晚的分支，在第二天开场重新征得住户同意延至第四天；第四天所有分支明确谈到第十天。未引入恋爱线。

## 关系与隐藏结局

四人初始关系为 0，十天选择累计增减，闲聊和重复读档不刷分。共 10 个隐藏后日谈和 1 个普通结局，可同时出现不同人物的后日谈。高关系还需要相应事件记录，低关系会出现疏远的生活变化。

具体条件与数值详见 `ENDING_RULES.md`（含剧透）；验证范围见 `TEST_REPORT.md`。

## 存档

结构版本 4，沿用站点键 `flat-war-topdown-v2` 以兼容已有自由探索版进度。历史结构 2/3 会在读取时升级为第一天状态，并保留原选择、信任和任务位置。已完成第一天的存档可直接从日终页继续第二天。原始长对话版本的另一套存档不导入。

主选择记录在按天排序的 ledger 中，关系值根据已提交选择校验；加载不会再次执行效果。位置定时保存，任务与对话节点即时保存。白天、夜间、床边、日终和跨天均可继续。损坏档保留并提示，确认重新开始后才替换。设置独立保存。不同域名、端口和浏览器的存档不共享。

## 素材和 AI 辅助

背景、家具和五个人物均为 AI 辅助编写的本地 Canvas 原创绘制，不依赖第三方图像。用户参考图只用于观察配色与生活氛围，未复制或分发原图。人物为统一风格的程序绘制原型，非最终精修手绘。

字体使用系统 Microsoft YaHei、PingFang SC、KaiTi、STKaiti 及回退字体，未分发字体文件。提示音由 Web Audio 本地合成，无外部录音、无背景音乐。Playwright 和 Edge 仅用于开发测试，不随游戏作为运行依赖。未下载安装外部降低 AI 感 skill。代码、剧情与美术需按实际赛事规则披露 AI 辅助。
